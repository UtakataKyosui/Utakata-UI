## Kbd [#kbd]

See [Kbd](/en/components/kbd) for detailed usage and the API.

Single keys and key combinations. Name a combination for screen readers with `aria-label` on `KbdGroup`.

`Kbd` and `KbdGroup` are display-only. `tabIndex`, `contentEditable` and keyboard event handlers cannot be specified. Implement shortcut handling in your application. For values that bypass TypeScript, dynamic JSX and custom CSS, check this constraint yourself.

<Component path="en/kbd" />

## Separator [#separator]

See [Separator](/en/components/separator) for detailed usage and the API.

Horizontal and vertical separators. By default they are decorative and hidden from assistive technology; use `decorative={false}` for a meaningful separator.

`Separator` is not interactive. `tabIndex` and `contentEditable`, which would make it focusable, are rejected by the types. Use a dedicated component for resizing.

<Component path="en/separator" />

## Input [#input]

See [Input](/en/components/input) for detailed usage and the API.

Single-line text input. Inside `Field.Root`, place it instead of `Field.Control` to associate the label, description and error with one input. Shows sizes, read-only and disabled states.

Each size and state of the built-in theme is verified in real browsers. Check custom backgrounds and CSS, actual text zoom, assistive technology output and wording comprehension yourself as well. `input.visual-theme` is a required browser rule and is kept separate from manual check results.

<Component path="en/input" />

## RadioGroup [#radiogroup]

See [RadioGroup](/en/components/radiogroup) for detailed usage and the API.

Single selection in vertical and horizontal layouts, including a disabled item. Arrow keys move and select. The group name references visible text with `aria-labelledby`, and each item is named by its own text.

<Component path="en/radiogroup" />

## Select [#select]

See [Select](/en/components/select) for detailed usage and the API.

Labeled single selection. Move with the arrow keys or by typing, select with Enter, and press Escape to close without changing the value and return focus to the Trigger. Use NativeSelect if you want the native picker.

<Component path="en/select" />

## InputOTP [#input-otp]

See [InputOTP](/en/components/inputotp) for detailed usage and the API.

Entering a multi-character one-time code. Paste and autofill are distributed across the slots, arrow keys and Home/End move between slots, and Backspace removes characters. `Field.Label` names the first slot and `getSlotLabel` announces the position of later slots. Completing the code never submits the form automatically.

<Component path="en/inputotp" />
## Combobox [#combobox]

See [Combobox](/en/components/combobox) for detailed usage and the API.

Single selection with a text input that filters the options. Focus always stays in the input: arrow keys move the highlight, Enter selects, and Escape closes the popup (Escape with the popup closed clears the input and the selection). Enter that confirms an IME conversion does not select. Name the input with `Field.Label` or similar, and put the no-results message in `Combobox.Empty`. `Combobox.Trigger` and `Combobox.Clear` are pointer-only buttons outside the Tab order and require `aria-label`. Multiple selection, asynchronous options and free-text values are out of scope. Use Select for a fixed list and NativeSelect for the native picker.

<Component path="en/combobox" />

## Slider [#slider]

See [Slider](/en/components/slider) for detailed usage and the API.

Choosing a value from a numeric range. Arrow keys move by step, Page Up/Down by larger amounts, and Home/End to the minimum and maximum. Show the value with `Slider.Value` and adjust the announced value with `format` or `getAriaValueText`.

<Component path="en/slider" />

## Collapsible [#collapsible]

See [Collapsible](/en/components/collapsible) for detailed usage and the API.

Opens and closes one region. The trigger is a button that conveys its state with `aria-expanded`, and collapsed content is not reachable with Tab.

<Component path="en/collapsible" />

Move between tabs with the arrow keys, Home and End, and switch with Enter or Space. Always specify the initial tab with `defaultValue` or `value`.

## Toggle [#toggle]

See [Toggle](/en/components/toggle) for detailed usage and the API.

A button that shows its pressed state with `aria-pressed` and fill and border. Icon-only toggles require `iconOnly` and `aria-label`.

<Component path="en/toggle" />

## Tooltip [#tooltip]

See [Tooltip](/en/components/tooltip) for detailed usage and the API.

Shows short supplementary text on hover and keyboard focus. Escape closes it, and it stays open when the pointer moves onto the Popup. The Trigger needs its own accessible name; do not make the Tooltip the only label or the only place required information appears. Content is text only; put interactive elements in a Popover.

<Component path="en/tooltip" />

## Popover [#popover]

See [Popover](/en/components/popover) for detailed usage and the API.

A non-modal popup tied to a Trigger. Name it with `Popover.Title` and describe it with `Popover.Description`. Base UI handles moving and restoring focus and closing on Escape or outside interaction.

<Component path="en/popover" />

## DropdownMenu [#dropdownmenu]

See [DropdownMenu](/en/components/dropdownmenu) for detailed usage and the API.

A list of button actions. Move between items with the arrow keys, Home/End and typing; Enter runs an item, closes the menu and returns focus to the Trigger. Disabled items are reachable with the arrow keys but do not run. Do not use it for page navigation; use a list of links instead.

<Component path="en/dropdownmenu" />

## AlertDialog [#alertdialog]

See [AlertDialog](/en/components/alertdialog) for detailed usage and the API.

Confirms important actions such as deletion. Opening it focuses Cancel, and clicking outside does not close it. Escape or Cancel closes it and returns focus to the original button.

<Component path="en/alertdialog" />

## Command [#command]

See [Command](/en/components/command) for detailed usage and the API.

An always-visible, searchable list of commands. It has no popup or selected value: run a command from `Command.Item` `onClick` (a click, or Enter on the highlighted item). Placed in a `Dialog` it becomes a command palette; close the `Dialog` from `onClick` and focus returns to the button that opened it. Focus stays in the input while the arrow keys move the highlight. Name the input with `aria-label` or similar and put a no-results message in `Command.Empty`. A shortcut such as Ctrl/Cmd+K that opens the palette is the consumer's responsibility; keep an operation that opens it without the shortcut. Use `Combobox` to choose and submit a value, and `Select` for a fixed list without search.

<Component path="en/command" />
## Sheet [#sheet]

See [Sheet](/en/components/sheet) for detailed usage and the API.

A modal panel attached to the top, right, bottom or left edge, built on Dialog. `side` selects the edge (default `right`). Tab stays inside the panel, and Escape, `Sheet.Close` and a press on the backdrop close it and return focus to the trigger. Long content scrolls inside the panel, and the slide transition is removed when reduced motion is requested. Always provide a `Sheet.Title` and a visible `Sheet.Close`.

<Component path="en/sheet" />

## Toast [#toast]

See [Toast](/en/components/toast) for detailed usage and the API.

A temporary notification that reports status without moving focus. Hovering or focusing pauses the auto-dismiss timer, and F6 moves to the notification region. Error notifications are shown without auto-dismiss (`timeout: 0`).

<Component path="en/toast" />

## InputGroup [#inputgroup]

See [InputGroup](/en/components/inputgroup) for detailed usage and the API.

Attaches icons, units and buttons before, after, above or below an existing `Input` or `Textarea`. Label it with `Field.Label`, hide decorative icons with `aria-hidden`, and associate meaningful text such as units with the input through `aria-describedby`. `align` only sets placement and does not reorder content, so write the DOM order to match the visual order. The attached button defaults to `type="button"`, so pressing it does not submit the form.

<Component path="en/inputgroup" />

## ToggleGroup [#togglegroup]

See [ToggleGroup](/en/components/togglegroup) for detailed usage and the API.

Groups `Toggle` items. Tab enters the group once, and the arrow keys matching `orientation`, Home and End move between items. By default only one item can be pressed; `multiple` lets items be pressed independently. Both modes can return to nothing pressed, so use `RadioGroup` when exactly one must be chosen. The group name (`aria-label` or `aria-labelledby`) is required by the types.

<Component path="en/togglegroup" />

## ButtonGroup [#buttongroup]

See [ButtonGroup](/en/components/buttongroup) for detailed usage and the API.

Joins the borders and corner radii of related `Button` elements. Each button is still reached one at a time with Tab, and variant, size, disabled state and type stay as set on each button. The group name (`aria-label` or `aria-labelledby`) is required by the types.

<Component path="en/buttongroup" />
