---
title: グラフの描画とデータ表
description: Chartに描画を組み込み、説明・凡例・データ表を用意する方法
---

`Chart.Plot` の中に SVG やグラフ描画ライブラリを配置します。描画領域にはアクセシブル名を付け、`Chart.Caption` でグラフの題名を、`Chart.Description` で主な傾向を伝えます。コード例と API は [Chart](/components/chart) を参照してください。

- 描画と凡例で同じ系列番号を使います。色に加えてマーカーの形や破線のパターンを揃えると、色だけに頼らず系列を区別できます。
- `Chart.Data` に `Table.Container` を使ったデータ表を配置します。描画と値を揃え、ホバーで表示する値もキーボードで取得できるようにします。
- `Chart.Plot` は支援技術にひとつの画像として伝わります。操作ボタンなどは描画領域の外に配置してください。
- 描画をアニメーションさせる場合は `--ui-chart-duration` を使い、利用者の動きを減らす設定に従います。強制配色でも線や塗りを区別できるか確認してください。
