---
title: テーマカラー
description: CSS変数でテーマカラーを変更し、アプリに反映する
---

Utakata UI の色は CSS カスタムプロパティで変更できます。コンポーネントを書き換えたり、新しいスタイリングライブラリを追加する必要はありません。

## 色を試す [#try]

ライト・ダークそれぞれの7色を変更できます。Preview 内の例に反映され、下に CSS と、選んだ配色を含む `init` コマンドが表示されます。docs 全体の配色には影響せず、リロードすると標準色に戻ります。

<Component path="theme" />

ソースを取り込んで使う場合は、Registry URLを確認し「初期化コマンドをコピー」を押してプロジェクトルートで実行してください。CLIの `--palette` は `light` / `dark` の色を `utakata.json` に保存し、配置先に `theme.css` を生成します。表示される依存インストール用コマンドを実行し、`theme.css` をグローバルエントリーから1度だけ読み込みます。その後は `utakata-ui add button` でコンポーネントを追加できます。コピーできない環境ではコマンド欄を選択して手動でコピーできます。[CLIの導入手順](/registry)も参照してください。

`--palette` は `primary`、`on-primary`、`surface`、`text`、`muted`、`border`、`danger` の部分指定に対応し、値は不透明な `#RGB` / `#RRGGBB` です。省略した色は標準色のままです。色の自動調整は行いません。

## アプリに反映する [#apply]

グローバル CSS でライブラリのスタイルを読み込み、その後に上書きを記述します。[CLI でソースを取り込んだ](/registry)場合は import を `src/components/utakata/styles/styles.css` の実際の配置先への相対パスに置き換えます。

```css
@import "@utakata-ui/react/styles.css";

:root {
  --ui-color-primary: #6d28d9;
  --ui-color-on-primary: #ffffff;
}

@media (prefers-color-scheme: dark) {
  :root {
    --ui-color-primary: #c4b5fd;
    --ui-color-on-primary: #1e1535;
  }
}
```

標準では OS の明暗設定に追従します。上書きする場合も明暗それぞれの文字色・背景色を組で設定してください。CSS のレイヤー外の上書きは、ライブラリの `utakata.tokens` レイヤーより優先されます。

## 変更できる変数 [#variables]

| 変数 | 用途 |
| --- | --- |
| `--ui-color-primary` | 主な操作・選択状態 |
| `--ui-color-on-primary` | メインカラー上の文字・アイコン |
| `--ui-color-surface` | 入力欄・ポップアップ等の背景 |
| `--ui-color-text` | 本文・ラベル |
| `--ui-color-muted` | 補足説明 |
| `--ui-color-border` | 枠線 |
| `--ui-color-danger` | エラー・危険な状態 |
| `--ui-color-on-danger` | 危険な操作の背景に載せる文字・アイコン |
| `--ui-focus-ring` | フォーカスの box-shadow |
| `--ui-radius-control` | コントロールの角丸 |
| `--ui-shadow-popup` | ポップアップの影 |

アプリのページ背景と本文色も必要に応じて指定します。

```css
body {
  background: var(--ui-color-surface);
  color: var(--ui-color-text);
}
```

## ユーザーがテーマを選べるアプリ [#user-selection]

設定画面の選択に応じて `document.documentElement.dataset.brand` を更新し、ルート要素で色を切り替えます。ルートに設定することで、Dialog など body 配下に表示する Portal にも色が届きます。SSR の初期描画は固定値にし、ブラウザー API はイベントハンドラーやクライアント側の処理で参照してください。

```tsx
<label htmlFor="brand">テーマカラー</label>
<select
  id="brand"
  defaultValue="blue"
  onChange={(event) => {
    document.documentElement.dataset.brand = event.target.value;
  }}
>
  <option value="blue">ブルー</option>
  <option value="violet">バイオレット</option>
</select>
```

```css
:root[data-brand="violet"] {
  --ui-color-primary: #6d28d9;
  --ui-color-on-primary: #ffffff;
}

@media (prefers-color-scheme: dark) {
  :root[data-brand="violet"] {
    --ui-color-primary: #c4b5fd;
    --ui-color-on-primary: #1e1535;
  }
}
```

ブルーは標準色をそのまま使います。この例は選択を保存しません。永続化する場合は、ストレージを使えない環境でも選択できるようにし、初期 HTML と保存した選択の反映もアプリ側で設計してください。

ライト・ダーク・システム設定を選べるようにするには、[ダークモード](/dark-mode)を参照してください。

## 配色変更後の確認 [#verification]

通常文字は 4.5:1、大きな文字は 3:1、識別に必要な UI 境界や状態は 3:1 を基準に、実際の背景と合成された色で確認します。上の比率は選択した不透明な2色の計算結果であり、画面全体の検証結果ではありません。

明暗それぞれで、通常・選択・エラー・フォーカス状態、キーボード操作、forced-colors、文字200%拡大とリフローを確認してください。エラーや選択を色だけで伝えず、文言や形を併用します。独自テーマの実ブラウザー・スクリーンリーダー検証は利用側の責任であり、このサンプルでの実機確認は未実施です。
